# Границы научной интерпретации фрактального анализа

Команда `lito dimension` оценивает фрактальную размерность загруженной
наблюдаемой береговой линии методом box-counting. Она не добавляет точки и не
изменяет геометрию контура перед вычислением.

## Что означают результаты

Оценка `D` характеризует масштабное поведение конкретного входного набора
данных. На неё влияют разрешение исходной береговой линии, диапазон размеров
ячеек и автоматически выбранное регрессионное окно. Поэтому значение `D` нужно
сопровождать числом масштабов, `R²`, доверительным интервалом и признаком
устойчивости по масштабам.

## Воспроизводимость

После запуска команды в `output/` сохраняются SVG-карта, log-log-график и
JSON-метрики. В метриках фиксируются контрольная сумма входной геометрии,
источник данных, параметры локальной проекции, размеры ячеек и точки
регрессионного окна.

В новой форме у размерности есть два представления: «Берег и аналитическая
сетка» и «График регрессии». Оба SVG строятся одним Go-анализом на выбранных
данных. Выбор основного отчёта сохраняется в задании, при повторе и в
JSON-паспорте; второй SVG и метрики остаются доступны. Аналитическая сетка
box-counting не является расчётной сеткой дна MSH.

По оси X графика отложен `ln(1/ε_rel)`, где `ε_rel = ε/L`, а `L` —
опорный размер области анализа. Размер ячейки `ε` в подсказке указан в метрах.
По оси Y — логарифм среднего покрытия по смещениям сетки. Список смещений
сохраняется в JSON. `boxes_covered` и подсказка SVG показывают одно округлённое
значение; положение точки и регрессия используют неокруглённый логарифм.
Поэтому подпись `N≈21` не означает, что регрессия вычислена по округлённому 21.

Начиная с ревизии `box-counting/reports-3`, пунктирная прямая использует
свободный член принятой регрессии из Go; он сохранён как `regression_intercept`.
Исправлено различное округление в SVG и JSON. D, R² и выбор масштабного окна
этими изменениями не пересчитываются по другой методике. Ревизия реализации
не означает научной аттестации источника.

```bash
go run ./cmd/lito dimension \
  --input data/coastline/black-sea.geojson \
  --output output/dimension \
  --manifest output/dimension/manifest.json
```

Пример выполняется из каталога CLI с сохранённым контуром MarineRegions.
Это граница IHO Sea Area, а не датированное спутниковое наблюдение берега.
Для собственного источника задайте свой проверенный GeoJSON; его разрешение,
происхождение и пригодность нужно оценить отдельно.
