# Карта береговой линии Чёрного моря

Команда создаёт научную географическую карту: полный контур, координатную сетку
с согласованными подписями широты/долготы, масштаб, CRS, источник, число вершин
и длину линии. Участок Сочи выделен отдельным цветом. Служебные предупреждения
и боковые карточки в SVG не выводятся.

```bash
./lito map black-sea
```

По умолчанию CLI и кабинет используют закреплённый полный GeoJSON морского
района [MarineRegions MRGID 3319](https://www.marineregions.org/gazetteer.php?p=details&id=3319)
из `data/coastline/black-sea.geojson`: 9 635 точек после нормализации, те же данные,
что у встроенной размерности и рисунков 1–2. Сеть для этого не нужна.
Паспорт рядом с файлом содержит SHA-256, CRS, дату источника и атрибуцию VLIZ.
Для самостоятельной загрузки актуального источника в CLI выполните:

```bash
./lito map black-sea --refresh
```

## Результаты

Команда всегда сохраняет результаты в `output/black-sea-map/`:

- `svg/black-sea-coast.svg` — научная карта с координатной сеткой и участком Сочи;
- `metrics/black-sea-coast.geojson` — два слоя GeoJSON: региональный контур и
  участок Сочи для открытия в ГИС.

Другой каталог можно задать флагом `--output`.

## Границы применимости

MarineRegions публикует геометрию **морского района**, поэтому его граница
годится для обзорной карты всего бассейна, но не заменяет подробную береговую
съёмку, кадастровую границу или проектный топографический план. Ограничения
хранятся в паспорте источника, GeoJSON и документации. Реальные ошибки или
предупреждения загрузки источника доступны в журнале выполнения.

Повреждённый снимок или недоступный явно выбранный источник не подменяются
схемой из 15 точек: команда завершится ошибкой. Для CERC используется отдельный
локальный участок с батиметрией и волновым рядом.

Данные MarineRegions предоставляются на условиях
[CC-BY и правил использования](https://www.marineregions.org/disclaimer.php).
Актуальную версию следует получать у MarineRegions; поставляемый снимок
сохранён для воспроизводимости расчётов, а не как обновляемый каталог источника.
