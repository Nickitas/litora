# Выбор источника береговой линии

В Лаборатории после загрузки береговой линии автоматически запускается отдельная
проверка геометрии Go. У малого набора результат виден в карточке; у научного
контура — рядом с выбранным входом в форме. Очередь, ошибка, отмена и отсутствие
проверки показаны отдельно. После завершения можно посмотреть замечания или
запустить проверку снова. Сбой очереди не удаляет сохранённый файл и его паспорт.

Проверка ищет совпадающие точки с точностью ядра до шести знаков координат,
самопересечения внутри каждой линии и выход за область Чёрного моря. Она
рассматривает все линии и кольца отдельно, сохраняя разрывы и острова, и не
исправляет исходные координаты. Успех не подтверждает точность съёмки, лицензию,
взаимное расположение разных колец или пригодность данных для прогноза.

В CLI эту проверку можно выполнить без загрузки и сети:

```bash
./lito coastline-check --input data/my-coastline.geojson \
  --output output/coastline-validation \
  --manifest output/coastline-validation/manifest.json
```

Отчёт `coastline-validation.json` содержит SHA-256 исходника, признак `accepted`
и замечания с номерами линий, точек и сегментов (с единицы). При отказе команда
сохраняет отчёт и manifest и возвращает ненулевой код. Поддерживаются двумерные
GeoJSON LineString, MultiLineString, Polygon, MultiPolygon, Feature и
FeatureCollection в WGS84. Кольца должны точно замыкаться. Пределы: 16 МиБ,
20 000 координат в пути, 50 000 всего и 200 замечаний. Достижение ресурсного
предела не считается успешной проверкой; исходник следует разделить на участки.

Малые наборы в кабинете по-прежнему ограничены LineString, 2–500 точками,
64 КиБ и 100 наборами на пользователя. Научные контуры проверяются отдельным
heavy-worker; при отключённом профиле интерфейс сообщает о недоступности
проверки и сохраняет загрузку.

CLI использует строгий порядок выбора источника:

- `--input PATH` читает только указанный локальный JSON/GeoJSON;
- `--source-url URL` включает удалённый режим, когда `--input` не задан;
- если оба флага не заданы, используется локальный файл по умолчанию
  `data/coastline/black-sea.geojson` — полный закреплённый контур MarineRegions.

Паспорт `data/coastline/black-sea.metadata.json` содержит источник, лицензию,
CRS (`EPSG:4326`, градусы), версию, размер и SHA-256 исходного GeoJSON.
CLI и встроенные сценарии кабинета используют одинаковый снимок без сети;
при повреждении снимка или паспорта расчёт завершается ошибкой.
После нормализации контур содержит 9 635 точек; это данные рисунков 1–2.
CLI и кабинет используют полный снимок или явно заданный пользователем контур.

При ошибке чтения `--input` команда завершается с ошибкой. Кэш и удалённый URL
не могут незаметно заменить явно выбранный локальный файл. Аналогично,
удалённый режим не подменяется локальным файлом: при недоступности URL и
отсутствии его кэша возвращается ошибка.

Примеры:

```bash
# Только локальный файл, даже если в кэше есть другой набор данных
./lito dimension --input data/my-coastline.json

# Явно включить удалённый источник
./lito source --source-url https://example.org/coastline.geojson

# Ошибка с ненулевым кодом; fallback на кэш или URL не выполняется
./lito erosion --input data/missing.json
```
