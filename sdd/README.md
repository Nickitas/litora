# SDD — разработка Litora по спецификациям

Начальная точка для работы над системой. SDD здесь означает **Specification-Driven
Development**: сначала фиксируем поведение и проверяемые требования, затем меняем код.

`sdd/` — единый источник правил разработки, требований, дизайна и эксплуатации.
Материалы для читателя сайта, научные методики и справочник CLI живут отдельно в
`packages/docs/content/`. Сайт не публикует инженерные правила SDD.
Научные методики здесь не дублируются. Пользовательские документы не содержат
ссылок на внутренние правила разработки.

Спецификация описывает как существующее поведение, так и явно отмеченные планы.
Наличие документа или шаблона deployment не означает, что функция уже реализована
или система прошла production-приёмку.
