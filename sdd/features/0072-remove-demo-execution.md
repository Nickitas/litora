# 0072 — расчёты CLI и API только по явным научным входам

- Статус: verified локально; не released.
- Дата: 21.10.2026; ветка `development`.
- Основание: пользователь расширил шаг 10 на CLI и подтвердил завершение
  принятых демонстрационных jobs с понятной ошибкой; также закрывается шаг 11.
- Область: CLI, contracts, API/worker, проверки и документация.

## Проблема и границы

`lito erosion` и `lito all` без файлов автоматически подготавливают демо Сочи;
те же ветви доступны по `--black-sea-sochi`/`--offline` и через API-виды
`erosion`/`all_demo`. Новый web уже не предлагает их (0071), но этого недостаточно.

Удаляются пути выполнения демонстрации и её автоматический сетевой загрузчик.
CERC и составной конвейер требуют явно указать контур (файл или явный источник),
волновой ряд и батиметрию. Поставляемые реальные контуры MarineRegions/OSM,
сохранённые научные файлы, математическое ядро и детерминированные тестовые
фикстуры сохраняются. CLI остаётся файловым адаптером, доступа к БД/S3 не получает.

## Контракты, риски и совместимость

Идентификаторы исторических видов остаются читаемыми в DTO истории и БД.
Новые запросы и повтор запрещены runtime-валидацией сервера; вызов builder
команды проходит ту же проверку. Схема БД и статусы не меняются. В очередь
добавляется обычное событие failed через существующий условный переход; отмена
или смена владельца worker не перезаписываются. Принятые задания не удаляются.

Научные формулы, отчёты и опубликованные ревизии методов не меняются: удаляется
транспортная подготовка демо. Собственные данные не получают автоматической
научной аттестации. Файлы прежних примеров и результатов не очищаются.

Обновлять API и worker/CLI одним согласованным выпуском; запущенный до обновления
старый worker может исполнять прежний код. Для полного прекращения демо остановить
его штатно перед заменой версии. Изменения в коде не означают обновление стенда.
