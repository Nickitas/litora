# 0035 — Калибровка CERC по собственным наблюдениям в кабинете

- Статус: реализовано локально; научная сквозная приёмка открыта.
- Владелец: Litora; дата: 11.10.2026; основа: ветка `development`.
- Область: contracts, API/worker, PostgreSQL, web, документация. Математика Go не меняется.

## Проблема и границы

Команда `lito calibrate-cerc` недоступна в ЛК. Новый `calibrate_cerc` принимает
приватные UUID контура, годового ряда волн, JSON батиметрии с паспортом и
независимых наблюдений годовой скорости береговой линии. Worker запускает
существующую Go-команду; API не выполняет калибровку и не принимает путь/URL.

В этот проход не входят внешние источники/стоки наносов и сооружения. Они
требуют отдельных ролей, паспортов и проверки совместимости. По умолчанию
минимальное покрытие ряда — 8766 ч; Go остаётся источником научной проверки.

## Контракт и совместимость

Обязательные `coastlineInputId`, `waveInputId`, `bathymetryInputId`,
`bathymetryMetadataInputId`, `observationsInputId` — UUID владельца.
`bathymetryResolution` — фактический шаг в градусах, явно заданный пользователем
и проверяемый Go против паспорта. Список `cercCoefficients` — 1–8 значений
`(0;1]` через запятую. Остальные численные параметры соответствуют конечному
набору флагов CLI. Роль `shoreline_observations_json` — JSON до 16 МиБ,
EPSG:4326/градусы; содержимое проверяет Go. Новая миграция только расширяет
CHECK роли. Jobs используют схему входа v6; worker сохраняет поддержку v1–v6.
Малый JSON-отчёт отображается рейтингом в ЛК без браузерного пересчёта; полный
отчёт всегда остаётся доступным как приватный артефакт.

## Риски и альтернативы

Калибровка может быть длительной и зависит от происхождения независимых
наблюдений. Она не доказывает пригодность модели за пределами проверенных
условий и не становится прогнозом. На первом этапе действует heavy worker и
его лимиты. Прямой JSON наблюдений в `POST /calculations` отклонён: приватные
объекты должны иметь паспорт, SHA-256 и проверку владельца. После миграции
выкатывать worker v6 раньше API/web; при откате завершить или отменить jobs v6.
