## Проблема и границы

Карточка `/lab/datasets` показывает паспорт, но не открывает сохранённую
геометрию. API умеет только создавать и перечислять наборы. Добавляем страницу
`/lab/datasets/:datasetId`, карту линии и её охвата, паспорт, скачивание сохранённых
байтов GeoJSON и переход в форму размерности с выбранным UUID.

Научная проверка остаётся в Go при расчёте. Просмотр не подтверждает точность
источника или научную пригодность. Новые данные, расширение лимитов, изменение
наборов, права администратора и универсальный выбор сценариев сюда не входят.

## Контракты и модель данных

`DatasetDetailDto extends DatasetDto` добавляет типизированную `geometry`.
`GET /api/datasets/:id` возвращает детальный DTO, `GET /api/datasets/:id/content`
выдаёт `application/geo+json` и безопасное фиксированное имя `dataset-UUID.geojson`.
Оба endpoint защищены AuthGuard, проверяют UUID и owner через существующий
параметризованный `getOwned`, затем читают S3 с лимитом. В ответах нет `object_key`,
bucket, владельца, токенов или signed URL; кеширование запрещено (`private, no-store`).
Геометрия проходит прежнюю структурную runtime-валидацию; научных вычислений API
не выполняет. Ошибки хранения и целостности → 503 с общей русской формулировкой.

Создание, таблица datasets, миграции, лимиты и старые DTO совместимы.
Скачиваются сохранённые байты, нормализованные при первоначальной загрузке,
а не исходное оформление пользовательского JSON. API client выполняет запросы
с тем же механизмом auth/refresh; web не обращается к S3 напрямую.

Карта использует существующие MapLibre/подложку и визуальный резерв на координатной
сетке. Подгонка охвата и проекция служат отрисовке, не рассчитывают научные метрики.
В форме запуска новый параметр `dataset` выбирает `dimension_dataset`; источник
остаётся UUID, существующий allowlist/API проверяет его при создании задания.

## Риски и альтернативы

- Публичный S3 или URL из web нарушили бы границы доступа. Скачивание идёт через
  защищённый API, два маршрута используют одну проверку целостности.
- Возвращать content в списке означало бы до 100 лишних файлов. Деталь грузится
  только после открытия страницы; экспорт запрашивает точные байты отдельно.
- Недоступный набор при переходе нельзя тихо подменять. Используется существующее
  состояние явного выбора замены; автоматическое создание примера блокируется.
- Одинаковые координаты/нулевой охват или отсутствие WebGL не должны ломать паспорт
  и экспорт; карта имеет резервное отображение. Современная подложка не дата съёмки.
- Общий gate имеет внешний блокер: ссылка 0018 на удалённый в рабочем дереве
  `todo/account-roadmap.md`. Удаление не относится к этой задаче.
