# 0029 — Параметры CERC и CSV для веб-демо Сочи

- Статус: реализовано в коде, сквозная приёмка на тестовой БД/S3 открыта.
- Дата: 06.10.2026; ветка `development`.
- Область: contracts, API, worker, web, документация и тесты.

## Проблема и границы

HTTP-сценарий `erosion` передавал CLI только `steps`, хотя демо Сочи в CLI
позволяет выбирать основные параметры one-line CERC и экспортировать CSV.
Добавляем эти параметры для уже закреплённого офлайн-набора. Собственные
берег, волны, батиметрия, источники наносов и сооружения, GIF и калибровка
остаются за пределами этого инкремента. Это демонстрация, не годовой прогноз.

## Требования и приёмка

| ID | Требование | Доказательство |
| --- | --- | --- |
| ERC-001 | ЛК показывает значения параметров CERC, единицы и пределы до запуска; сохранённый job можно открыть для изменения, а паспорт JSON сохраняет эти значения без произвольных полей | Браузерные тесты формы, повтора и паспорта |

| ERC-003 | Worker передаёт Go ровно проверенные значения, закреплённый offline-набор и фиксированное имя CSV внутри каталога результата | Контрактный тест аргументов и локальный CLI smoke |
| ERC-004 | Новые jobs получают input schema v3; worker читает сохранённые v1/v2 с прежними defaults | Тесты версий и сборка |
| ERC-005 | CSV появляется в manifest и приватных результатах, а демо-статус и происхождение не теряются | Локальный CLI smoke; сквозной тест на отдельной БД/S3 подготовлен, но ещё не запущен |

## Контракты и совместимость

`ErosionDemoOptionsDto` определяет `steps`, индекс разрушения, высоту бермы,
глубину замыкания, пористость, коэффициент CERC, расстояние отбора глубины,
предел смещения, радиус поиска батиметрии и переключатель/формат CSV.
Параметры без новых входных файлов; новая SQL-миграция не нужна. API сохраняет
нормализованные defaults. Старые клиенты с `{steps}` продолжают работать.
Файл CSV получает только фиксированное имя `erosion-metrics.csv`, которое Go
размещает в своём `csv/` каталоге вывода. `--output`, `--offline` и локальный
набор остаются серверными решениями. `inputSchemaVersion=3`; версии 1 и 2
worker не отвергает, а нормализует через текущий валидатор.

## Риски и альтернативы

Параметры существенно меняют метрики, поэтому форма не называет результат
калиброванным или годовым. Численные пределы API уже области допустимости Go,
чтобы исключить нулевые значения, которые CLI трактует как defaults, и
неограниченный ресурсный ввод. CSV увеличивает число файлов и размер результата,
но остаётся под бюджетом обычного worker. Альтернатива передачи CLI-строки
отклонена из-за shell/пути и отсутствия явной валидации.
