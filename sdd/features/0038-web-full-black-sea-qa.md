# 0038 — QA-03 полного контура через личный кабинет

- Статус: реализовано локально; сквозной ресурсный замер и научная приёмка открыты.
- Владелец: Litora; дата: 12.10.2026; основа: `development`.
- Область: Go CLI, contracts, API/worker, web, PostgreSQL, документация.

## Проблема и границы

`lito seabed check-full` доступен только локально. Для web нужны пять приватных
входов: плоская MSH, отчёт её генерации, полный GeoJSON-контур, производная
батиметрия JSON и её паспорт. Старый `mesh-report` связывает MSH только путём,
который меняется при staging worker. Новые отчёты получают SHA-256 MSH; Go
проверяет его при переносе. Старый отчёт без SHA остаётся допустимым в CLI,
когда путь не изменился, но не выдаётся за переносимый паспорт.

В этом этапе не запускаем Gmsh, не загружаем внешние URL, не меняем формулы
QA-03 и не объявляем результат publication-ready. Ограничиваем web-запуск
плоской MSH размером 256 МиБ до чтения Go; реальные RAM/время ещё не измерены.

## Контракты и модель данных

Новый `kind=seabed_check_full` и роль `mesh_comparison_report_json` в
`packages/contracts`. Входная схема jobs v10; worker сохраняет совместимость
v1–v9. Миграция `013_mesh_comparison_report_input.sql` только расширяет CHECK
роли научного входа. CLI `mesh-comparison/v1` получает необязательное поле
`mesh_sha256` у успешного запуска. CLI `check-full` по умолчанию сохраняет
прежний режим, web передаёт `--max-mesh-mib=256`.

Контур и батиметрия сохраняют исходные CRS/единицы и паспорта. Сверка MSH и
mesh-report производится Go по SHA-256; совпадение имени файла не требуется.
SQL owner-filter и SHA-256 после S3 download остаются обязательными.

## Риски и альтернативы

Вместо переписывания путей внутри отчёта выбран digest: перепись скрыла бы
исходное происхождение. Отказ от ограничения MSH опасен на 12-ГБ worker;
256 МиБ — предварительный предел, не гарантия памяти. Старые отчёты без
digest после переноса требуют повторного `mesh` в новой версии CLI. Пять
входов могут быть научно несовместимы несмотря на совпадение SHA сетки:
существующие Go-проверки паспорта, проекции и QA-03 остаются обязательными.
