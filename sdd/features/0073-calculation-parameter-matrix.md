- Область: документация SDD; шаг 12 [аудита](../../todo/AUDIT.md).

## Проблема и границы

Перед перестройкой формы нужно сверить поля web, contracts, runtime-валидацию
API, построитель команд worker и параметры Go. Технический предел и текущее
значение по умолчанию не подтверждают научную применимость.

Результат — [матрица](../calculation-parameter-matrix.md) всех доступных
пользовательских сценариев с входами, флагами, единицами, пределами, текущими
значениями и условиями выбора. Служебные и удалённые сценарии обозначаются
отдельно. Обнаруженные несоответствия фиксируются для следующих шагов.
Изменение формы, DTO, allowlist, научных методов, defaults и загрузка данных
в эту задачу не входят. Научные методики остаются в публичной документации.

## Контракты и модель данных

Контракты, статусы, ownership, Swagger и хранение не меняются. Матрица описывает
фактическую реализацию на указанную дату; при изменении соответствующих полей её
нужно обновлять вместе с кодом. Научные формулы в TypeScript не добавляются.

## Риски и альтернативы

Главный риск — представить прежний default или архивный пресет как рекомендацию
для любого участка. Для каждого семейства параметров требуется обозначить
источник выбора и отсутствие универсального обоснованного диапазона. Второй
риск — скрыть несовпадения web/API/Go: они перечисляются отдельно, с будущей
проверяемой приёмкой. Генерация документа только из Swagger недостаточна:
он не описывает все условные преобразования и проверки Go.
