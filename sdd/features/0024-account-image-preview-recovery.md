## Проблема и границы

Полная страница и сравнение вставляют каждый артефакт с `image/*` прямо в `img`.
Ошибки загрузки по истёкшему signed URL или отсутствующему объекту не имеют
отдельного состояния. Не все MIME из семейства `image/*` гарантированно
поддерживаются браузером; журнал нельзя считать визуальным результатом.

В этом срезе отображаем только `output` с MIME из разрешённого списка через
`img`, показываем загрузку и понятную ошибку. На полной странице повтор
переиспользует owner-scoped `GET /api/calculations/:id`, который выдаёт свежие
ссылки. Ошибки прямой загрузки остальных форматов по ссылке браузер не может
достоверно различить без отдельного API; полный viewer JSON/GeoJSON/таблиц и
скачивание с автоматическим восстановлением остаются следующими задачами.

## Контракты и модель данных

Используются существующие `CalculationArtifactDto` и `CalculationJobDto`.
`downloadUrl` остаётся краткоживущим и не копируется в текст ошибок, логи или
документацию. Разрешённые MIME: SVG, PNG, JPEG, WebP, GIF. SVG загружается
только как внешний ресурс `img`, без HTML-вставки и разбора в браузере.
Категория должна быть `output`. Смена URL сбрасывает только локальное состояние
его предпросмотра, не состояние job.

## Риски и альтернативы

- Событие `img.onerror` не сообщает HTTP-код: интерфейс не утверждает, истёк
  URL или объект исчез. Повторный запрос может вернуть новый URL, но не
  восстанавливает отсутствующий объект в S3.
- Proxy для файлов через API позволил бы точно диагностировать 404/403, но
  расширил бы права, нагрузку и контракт. Он не вводится в этом UI-срезе.
- Не используем `fetch` signed URL для предпросмотра JSON: CORS S3 для чтения
  браузером не является частью текущего контракта.

## Проверки и выпуск

Новой зависимости, миграции, нового endpoint, прав и downtime нет. Откат —
возврат прежнего React-предпросмотра. `pnpm verify` прошёл; полный
`pnpm --filter litora-web test:e2e`: 25 пройдено, один live-сценарий пропущен.
E2E проверяет узкий экран 360 px, тёмную тему, доступность повтора с клавиатуры,
ошибку при 403, новый URL и исключение журнала/HTML из предпросмотра. Ручная
визуальная и screen-reader проверка обеих тем не выполнена. Прямое скачивание
неизображений пока не имеет восстановления.
