# 0037 — Полный волновой ряд CERC по собственным входам

- Статус: реализовано локально; сквозная ресурсная и научная приёмка открыта.
- Владелец: Litora; дата: 12.10.2026; основа: `development`.
- Область: Go CLI, contracts, API/worker, web, документация.

## Проблема и границы

CLI допускает `--steps=0`, но web ограничен первыми 48 состояниями. Простое
снятие ограничения создаёт тысячи SVG, а полный JSON сейчас сериализуется
целиком в памяти. Для собственных `erosion_file` и `all_file` открываем весь
загруженный ряд при явном выборе пользователя и ограниченном числе SVG.
Демо Сочи остаётся ограниченным. Научные формулы CERC и полный состав
`longshore-cerc.json` не меняются. Это не обещание годового прогноза.

## Требования и приёмка

| ID | Требование | Given / When / Then | Доказательство |
| --- | --- | --- | --- |
| CERC-FULL-001 | Весь ряд, а не первые 48 записей | Свой ряд до 10 000 состояний и контур до 200 точек, `steps=0` → Go рассчитывает все состояния и сохраняет полный JSON | Go-тест и API-тест аргументов; сквозной запуск ожидается |
| CERC-FULL-002 | Ограниченные изображения без потери первого/последнего состояния | `svgMaxFrames` 2–128 → Go создаёт не более выбранного числа SVG эрозии с исходными номерами шагов | Go-тест выбора кадров и manifest |
| CERC-FULL-003 | Ресурсные ограничения до расчёта | Превышение числа состояний/точек → Go отказывает до CERC; GIF и широкий CSV в полном режиме → API 400 | Go и API отрицательные тесты |
| CERC-FULL-004 | Повтор и экспорт метаданных | Сохранённый `steps=0` → форма и паспорт сохраняют 0 и лимит SVG | Web E2E и тест экспорта |
| CERC-FULL-005 | Не расширять права | Входы остаются UUID владельца, worker передаёт только фиксированные флаги и проверяет SHA-256 | Существующие проверки owner/role, негативный тест DTO |

## Контракты и модель данных

Для `erosion_file` и `all_file` вход v9 допускает `steps=0` и поле
`svgMaxFrames` (2–128 при полном ряде; 0 при обычном). Worker добавляет
фиксированные `--max-wave-conditions=10000` и `--max-coast-points=200` только
для полного режима. CLI по умолчанию остаётся совместимым: эти флаги равны
нулю без лимита, `--svg-max-frames=0` рисует все состояния. API не принимает
пути, URL или пользовательские значения серверных лимитов. Миграция БД не
нужна: вход уже хранится в JSONB. Worker продолжает принимать v1–v8.

## Риски и альтернативы

Полный ряд может долго считаться и создать крупный JSON; потоковая запись
уменьшает пиковую память сериализации, но не память самой модели. Worker
сохраняет текущие 4 часа, 512 файлов и 8 ГиБ результата. При превышении
этих пределов job завершится ошибкой. Лимиты 10 000/200 консервативны и
нуждаются в замере на тестовом стенде. GIF отключён в полном режиме, потому
что код держит все кадры в памяти; широкий CSV исключён из-за тысяч колонок.
Альтернатива — включить `steps=0` без ограничений — нарушает бюджет worker.
