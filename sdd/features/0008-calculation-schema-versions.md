# 0008 — версии схем входа и результата расчёта

- Статус: реализован локальный срез A3; staging не подтверждён.
- Область: contracts, PostgreSQL, API, worker, Swagger.

## Граница

Версии ниже относятся к **формату данных**, не к научной версии алгоритма Go.
`coreVersion` остаётся SHA-256 бинарника. Изменение научного метода без
изменения DTO требует отдельной идентификации и проверки паритета.

## Контракт v1

| Объект | Формат v1 | Ограничение |
| --- | --- | --- |
| Вход job | `kind` и канонический `input`: `{}` для `dimension`/`map`, `{steps: 1..48}` для `erosion`, `{datasetId: UUID}` для `dimension_dataset` | Произвольные флаги, URL и пути запрещены |
| Результат job | Внешняя оболочка `fileCount`, `totalBytes`, `scenario`, `metrics`; `provenance` добавляет паспорт входов для новых результатов | `metrics` содержит разнотипные JSON-отчёты Go и пока не версионирует их внутреннюю схему; старые результаты могут не иметь provenance; файлы — отдельные приватные артефакты |
| Набор линии | GeoJSON `LineString`, `[longitude,latitude]`, EPSG:4326/WGS84, градусы; метаданные источника, лицензии, размера и SHA-256 | Вертикального датума, nodata и времени у 2D-линии нет; их нельзя выдумывать |

В БД `input_schema_version=1` задаётся при создании нового job. Миграция
маркирует старые jobs четырёх известных видов как вход v1; импортированные и
неизвестные виды остаются `NULL`. Старый `result_summary` не маркируется
задним числом: `result_schema_version=NULL`. Новый worker выставляет версию
результата 1 только одновременно с переходом в `succeeded`. `NULL` или
неизвестная версия входа отклоняется до запуска Go. Для набора `schema_version=1`
проставляется существующим и новым строкам, поскольку форма сохранённого
LineString не менялась.

## Приёмка и дальнейшая работа

- Новый job и dataset возвращают версии в API/Swagger, без S3 key.
- Worker не выполняет неизвестный формат; тест покрывает `NULL`, 0 и 2.
- Старые результаты сохраняют `NULL`, а не ложную v1.
- Для будущих волн, батиметрии и MSH нужны самостоятельные схемы с CRS,
  горизонтальным/вертикальным датумом, единицами, nodata, временем, точной
  версией источника и подтверждёнными правами. Этот срез их не открывает.

Откат кода возможен без удаления новых колонок; миграцию не переписывать после
применения. Если нужно сменить форму v1, вводить v2 с явным чтением старых
заданий, а не переименовывать текущую версию.
