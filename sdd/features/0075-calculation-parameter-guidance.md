- Статус: verified (локально, без развёртывания).
- Дата: 22.10.2026; HEAD `2d94f82`, локальные 0071–0074 сохранены.
- Область: contracts / API / web / документация; шаг 14 аудита.

## Проблема и границы

Форма и API подставляют физические параметры CERC без сведений об участке,
включая нулевые граничные потоки. Часть HTML-пределов расходится с API, шаг
батиметрии допускается API до 1°, хотя Go ограничивает его 0.1°. Пустые поля
адаптации скрывают эффективные defaults API. Подсказок под параметрами недостаточно.

Вводим общий контракт технических ограничений и пояснений; используем его в
API и web. Параметры, требующие данных участка, запрашиваются явно. Настройки
экспорта, защиты ресурсов и алгоритмические стартовые настройки остаются
предзаполненными с указанием основания. Универсальные научные рабочие диапазоны
не объявляются. Математика, научные методы, CLI-defaults и права не меняются.
Перенос сохранённых параметров при повторе сохраняется с прежними ограничениями
интерпретации; перенос сам по себе не подтверждает научную пригодность.

## Требования и приёмка

| ID | Требование | Given / When / Then | Доказательство |
| --- | --- | --- | --- |
| PARAM-01 | Нет скрытых физических defaults | Новый CERC/калибровка без параметров участка → пустые обязательные поля и отказ API до создания задания | API + browser |
| PARAM-02 | Ноль не заменяет неизвестность | Пустой поток → не превращается в 0; явно введённый 0 сохраняется как выбранное граничное условие | API + browser |
| PARAM-03 | Общие пределы | Поле web → те же min/max/step и единицы, что runtime API; батиметрия ≤0.1° | Границы/нечисловые входы + browser |
| PARAM-04 | Понятный выбор | Поле → технический диапазон и условие выбора под полем; defaults имеют объяснимое основание | UI обеих тем/узкий экран |
| PARAM-05 | Повтор и совместимость | Сохранённые нормализованные параметры → повтор и builder без подмены; неизвестные остаются пустыми | API/worker/browser regression |

## Контракты и совместимость

Требуем явно параметры CERC, которые зависят от участка: breakingIndex,
bermHeight, closureDepth, porosity, cercCoefficient (для моделирования),
offshoreSampleDistance, maxBathymetryGap, leftBoundaryTransport,
rightBoundaryTransport. Для калибровки также явные cercCoefficients и
maxObservationDistance, фактический bathymetryResolution. Для сборки и проверки
дна maxSourceDistance задаётся по покрытию источника явно.

Технические ограничения вынесены в contracts; HTTP остаётся разрешённым набором
видов и параметров. Старые сохранённые нормализованные jobs содержат эффективные
значения и остаются исполнимыми. Неполный новый запрос получает понятную ошибку.
Исторические DTO/defaults нужны для чтения и тестовых протоколов, не для
автоматического заполнения нового исследования. Миграций и новых зависимостей нет.

## Риски и альтернативы

Нельзя выводить физические значения из имени файла, района или разрешения сетки.
Если проверенного параметра нет в контракте выбранных данных, требуется ввод.
CLI сохраняет более широкий самостоятельный интерфейс; сужение HTTP не
переписывает научные ревизии. Общие transport-ограничения не заменяют проверки
совместимости и численной применимости в Go.
