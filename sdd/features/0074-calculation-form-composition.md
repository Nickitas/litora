## Проблема и границы

Поля CERC сейчас предшествуют входным файлам; порядок и нумерация зависят от
сценария, а перед запуском нет отдельного блока результата и готовности входов.
API скрывает выключенные heavy-возможности, поэтому общий селектор не может
объяснить их недоступность. Нужна единая последовательность: тип расчёта,
исходные данные, параметры, результат.

Используем действующие Radix/shadcn, существующие поля и api-client. Каталог
остаётся серверным. Не меняем научные формулы, defaults, числовые пределы,
индексные профили, очередь или права. Шаги 14–15 (обоснованные defaults и
компактная справка) остаются отдельными задачами.

## Контракты и совместимость

Добавить необязательные `available` / `unavailableReason` в `CalculationKindDto`
и `includeUnavailable` в query каталога. По умолчанию API сохраняет прежнюю
фильтрацию heavy; новый запрос возвращает также выключенные виды с причиной.
Отсутствие available от прежнего сервера означает прежнее доступное состояние.
`selectable=false` и удалённые демо по-прежнему не входят в пользовательский
выбор. POST проверяет heavy независимо от каталога; отсутствие работающего
worker не выводится из одного конфигурационного флага.

Миграций, расширения HTTP-флагов и новых сервисов нет. Файлы остаются приватными;
форма показывает названия и состояние выбора, а не серверные пути/signed URL.

## Риски и альтернативы

Перенос JSX может повредить повтор и загрузки: сохраняем действующие state,
handlers и поля, выделяем только общие структурные секции и итог готовности.
Копировать каталог CLI или распределение heavy на клиент нельзя — доступность
возвращает API. Отдельный wizard с обязательными переходами усложнил бы повтор
и редактирование, поэтому сохраняем одну прокручиваемую форму.

Для размещения самостоятельных форм загрузки в секции данных основная форма
запуска имеет постоянный ID, а её числовые поля связываются через нативный
атрибут `form`. Кнопка запуска использует тот же ID. Это сохраняет HTML
валидацию required/min/max и отправку по Enter без вложенных form. Загрузки
остаются самостоятельными формами и не отправляют расчёт при сохранении файла.
