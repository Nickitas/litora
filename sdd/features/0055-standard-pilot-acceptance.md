## Команды и ограничения результата

- `pnpm verify` с `TEST_DATABASE_URL=.../litora_test_acceptance` — пройден
  после всех изменений этого локального среза. Для кандидата выпуска повторить
  на его точном SHA.
- `pnpm test:api:db` — 106/106 без пропусков. `pnpm --filter litora-api
  test:migrations` — 17 миграций на чистой временной БД, повтор без изменений.
- `pnpm --filter litora-web typecheck`, `lint`, `build` — успешно; lint оставил
  одно существующее предупреждение TanStack Table, Vite — предупреждение о
  крупных чанках.
- Общий mock Playwright-прогон после исправления устаревшего текста:
  69 прошли, 1 live-сценарий пропущен по настройке. Live-сценарий отдельно
  прошёл 1/1 с настоящим API/worker/S3 и одноразовым приглашением.
- Прямой локальный `node dist/main.js` с Node.js 22.12 завершился на TS-export
  пакета contracts; API через `tsx` работал. Готовый runtime-образ с другой
  версией Node.js здесь не проверялся; это обязательная проверка [0049](0049-prebuilt-vps-delivery.md).

## Открытые проверки до закрытого пилота

- На выделенном staging повторить этот путь для точных image digest, реального
  TLS и приватного bucket, включая обзор с реальным API после более 100 jobs.
- Дополнить сквозной сценарий зависимым источником, подменённым S3-объектом,
  timeout, crash/restart, сменой web-релиза и сроком signed URL.
- Пройти клавиатуру, 360 px, 200% zoom и обе темы вручную на маршрутах пилота.
- Измерить ресурсы heavy отдельно и выполнить совместный restore PostgreSQL+S3
  на чистом стенде. Этот локальный протокол не подтверждает RPO/RTO или выпуск.

В тестовом окружении использовались только одноразовые приглашения и учётные
записи; коды, токены и подписанные URL в протокол не внесены. После проверки
тестовые процессы и контейнеры останавливаются; данные tmpfs уничтожаются
вместе с конкретными контейнерами.
