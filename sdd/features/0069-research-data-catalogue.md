## Границы

На `/lab/datasets` вместо трёх учебных контуров показываются 24 подготовленных
фрагмента из шага 07. Пользователь выбирает подходящий участок по превью,
назначению и паспорту, сохраняет приватную копию с собственным названием и
открывает её для проверки геометрии. Наличие карточки не создаёт dataset или job.
Полный контур моря, временные ряды, прогноз и замена демонстрационных расчётов
относятся к последующим шагам.

## Контракты и риски

Используется существующий `POST /api/datasets` через api-client, без изменения
DTO, owner-проверок, S3, worker, миграций и математических методов. Квота 100
проверяется также сервером. Научные вычисления остаются в Go; SVG-превью —
только отображение исходных координат. Исходные снимки OSM в browser не попадают.

При сохранении список перечитывается перед POST и после неопределённой ошибки;
совпадение проверяется по canonical SHA-256, источнику, версии, лицензии и CRS,
а не названию. Это защита интерфейса от случайного повтора, а не новый серверный
протокол идемпотентности: одновременное создание из независимых клиентов
существующий endpoint не сериализует по содержимому.

## Проверки и выпуск

`pnpm typecheck`, web lint, `pnpm test:web`, `pnpm test:api`, `pnpm build:web`
и `pnpm test:bundle` пройдены. В API — 121 успешный тест, 9 DB-тестов пропущены
без `TEST_DATABASE_URL`. Превью 24 контуров, сохранение с паспортом и переход
к проверке дополнительно проверены двумя browser-тестами против собранного web
через локальный `vite preview`; API в этих UI-проверках замокан.

Визуально проверены 1440/360 px и обе темы, клавиатура, загрузка и повтор после
сетевого сбоя, отказ при несовпадении SHA-256, восстановление после потери ответа,
изменение квоты и собственные имена. Полный `pnpm test:web:e2e`: 109 пройдено,
один `@live`-тест пропущен без явно включённого живого стенда. После переноса ошибок в карточку
сохранения и уточнения сообщений о доступности повторены все 16 затронутых
сценариев — успешно. Ошибка загрузки и несовпадение checksum также проходят
повторную загрузку; использованы обычные запросы к поставляемым GeoJSON,
поскольку ошибка dynamic import могла блокировать повтор до перезагрузки страницы.

`pnpm verify` не пройден: `check:workspace` останавливается на прежней ссылке
`sdd/features/0018-account-workspace-navigation.md` на удалённый
`todo/account-roadmap.md`. Эта ссылка не менялась. Web lint сохраняет прежнее
предупреждение `useReactTable` в `calculation-history-table.tsx`; Vite — предупреждение
о крупном chunk. Новых предупреждений нет.

Go test/vet и DB/S3-интеграция не повторялись: вычисления, API, worker, миграции
и хранилище не менялись; UI использует проверенный путь сохранения и проверки
из 0067. Это не утверждение о сквозном запуске на живом стенде.

Изменение не требует новых секретов, зависимостей, миграций или внешних запросов
при сборке. Новые файлы малы, закреплённые исходники OSM не попадают в web.
Развёртывание и коммит не выполняются. Откат — предыдущая web-сборка; созданные
приватные наборы совместимы с прежним API и остаются доступны в своём списке.
