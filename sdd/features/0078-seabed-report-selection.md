# 0078 — выбор подтипа отчёта по модели дна

- Статус: implemented; научная пригодность конкретных моделей проверяется отдельно.
- Дата: 22.10.2026; ветка `development`, шаг 17 аудита.
- Область: contracts, валидация API, web и документация; без миграций и новых зависимостей.

## Проблема и границы

Блок «Карты и сетки дна» дублирует тип расчёта, а выбор рисунка 3 или 5
не сохраняется в задании. По матрице 0077 нужны три подтипа: обзор глубин,
поле размера и фрагменты фактической сетки. Их строят существующие Go-команды
`seabed render` и `seabed adapt` на явных реальных входах.

Выбранный результат сохраняется в `input.reportType`, проверяется вместе
с kind и выделяется на странице задания. Остальные артефакты Go доступны.
Математика, ревизии методов, файлы Go, Gmsh и архивный повтор не меняются.

| REPORT-04 | Переключение и повтор | Совместимые UUID и введённые параметры не теряются при смене подтипа; повтор восстанавливает сохранённый выбор |
| REPORT-05 | Результаты | Выбранный SVG выделен в job; есть ожидание, отсутствие выбранного файла после успеха и чтение legacy без reportType |
| REPORT-06 | Доступность | Серверные ограничения не обходятся; клавиатура, 360 px, обе темы и подготовка отсутствующей модели проверены |

## Контракты и совместимость

В contracts — каталог подтипов с kind, именем файла, русскими подписями
и безопасным поиском по внешнему значению. `reportType` необязателен:
старые клиенты и jobs без него сохраняют прежний вывод всех отчётов.
Параметр хранится в существующем JSON входа; миграция не нужна. API client
использует прежний CreateCalculationDto. Права и получение signed URL
не меняются. Swagger описывает допустимые сочетания.

## Риски и альтернативы

Фильтрация вычислительных артефактов могла бы скрыть нужные паспорта:
выделяем основной отчёт, сохраняя дополнительные. Клиентское состояние
без серверной валидации теряло бы выбор при повторе и обновлении страницы.
Нет гарантии архивного тождества без входов и паспортов из матрицы 0077.

## Результат и доказательства

В contracts добавлен каталог `seabedReports`: подтип, совместимый kind,
русские подписи и имя выходного SVG. API принимает только совместимые
`bathymetry_overview`/`mesh_details` для render и `size_field` для adapt;
прочие значения и типы отклоняет до создания job. Swagger описывает
общий enum и ограничения в ветках oneOf. Список scientific UUID и
CLI-команды не расширены. API client использует существующий контракт.

В web прежний picker удалён. В одном типе «Отчёты по модели дна» селектор
подтипа меняет требуемые UUID и параметры. Переключение сохраняет выбранные
файлы и введённые значения; переходы workflow и повтор работают. Подготовка
отсутствующей модели доступна из раскрывающейся подсказки. 3D-настройки
дополнительного отчёта свёрнуты; архивный пресет 50–250 м переименован и
отделён от примера 200–1000 м. В результате выбранный SVG показан первым,
без дублирования в галерее; дополнительные отчёты сохранены. Известный
совместимый подтип входит в безопасный JSON-паспорт. Legacy без поля
показывает прежнюю галерею. Состояния ожидания и отсутствующего после
успеха файла проверены отдельно.
