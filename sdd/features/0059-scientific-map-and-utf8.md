# 0059 — Научная карта, удаление схемы и UTF-8 журналов

- Статус: реализовано, локальная техническая приёмка пройдена.
- Дата: 20.10.2026, исходный SHA `2d49016`, продолжение незакоммиченного 0058.
- Владелец: команда Litora, поручение пользователя от 20.10.2026.
- Область: Go CLI, отчёты, S3/worker/API, документация.

## Проблема и границы

После перехода на полный контур прежняя схема из 15 точек всё ещё лежит в
репозитории, тестах и примерах. Пользователь поручил полностью удалить её.
Карта использует универсальный шаблон с лишними карточками и предупреждениями,
без координатной сетки. Нужен компактный научный рисунок.

Для указанного пользователем расчёта `dd78fc1c-73a6-499b-99ef-ce6e9c3e97a0`
журнал содержит корректный UTF-8 без U+FFFD, SHA-256 совпал с указанным:
`8ab43460251de81273c2d7a9addccd94bb4074c2318dae4664eaf314b3c881be`.
S3 отдаёт `text/plain` без charset. Кроме того, worker декодирует каждый chunk
самостоятельно и может повредить многобайтовый символ на границе chunks.

## Требования и приёмка

| ID | Требование | Проверка |
| --- | --- | --- |
| MAP-01 | Схема удалена, примеры/тесты/константы не обращаются к ней | Поиск по репозиторию, `pnpm verify` |
| MAP-02 | SVG содержит полный контур, координатную сетку с согласованными осями, масштаб, CRS, источник и краткие численные сведения | Реальный CLI/worker, XML и визуальная проверка |
| MAP-03 | В SVG нет боковых карточек, общего текста про фрактальные итерации и блока предупреждений | Тест SVG; реальные предупреждения источника остаются в журнале |
| LOG-01 | Текстовые артефакты отдаются с UTF-8, включая ссылки на старые журналы | HTTP Content-Type, неизменность байтов/SHA-256 |
| LOG-02 | Кириллица сохраняется при произвольном разбиении stdout/stderr и ограничении длины | Тест каждого положения разрыва многобайтовых символов |

## Контракты и совместимость

DTO и MIME-типы в БД не меняются: web продолжает распознавать SVG по базовому
типу. Charset задаётся в S3 HTTP-метаданных и подписанной выдаче. Существующие
байты артефактов, SHA-256 и manifest не переписываются. Для старого журнала
кодировка задаётся параметром подписанной выдачи без изменения объекта S3.
Ревизия `black-sea-overview` повышается; GeoJSON сохраняет оба прежних слоя.
Научные ограничения источника остаются в паспорте и документации.

## Риски и альтернативы

Нельзя заменять геометрию интерполяцией и объявлять её новыми измерениями.
Универсальный эталон длины, привязанный к имени удалённой схемы, удаляется:
длина зависит от источника и разрешения. Контроль полного снимка и численные
регрессии 0058 сохраняются. Бинарные MIME-типы не получают charset.
Используются штатные Go renderer, Node streams и S3 без новых зависимостей.
