и доступные паспорта. Изображения не подставляются в результаты расчётов.

| ID | Требование | Вход / действие / результат | Доказательство |
| --- | --- | --- | --- |
| FIGMAP-01 | Полный реестр | Каждый SVG → размер, SHA-256, содержательный вид отчёта | XML / hash / матрица |
| FIGMAP-02 | Проверка повторов | Повторяющиеся имена/номера → доказанные дубликаты или отличающиеся варианты | Побайтовое сравнение |

| FIGMAP-05 | Корректная трактовка | Поле размера не называется построенной сеткой; анонимный номер не доказывает генератор | SVG / связанный отчёт или явно записанный пробел |

## Контракты и риски

DTO, научные методы, ревизии, хранение, права и UI не меняются. Крупные
архивные артефакты остаются вне Git. Путь к локальному архиву не является
публичным контрактом или гарантией наличия на другой машине. Для точного
повтора нужны сами входы, их SHA-256, параметры, версии ядра и Gmsh.
Диагностика не разрешает подмену исходных данных или исправление генераторов
в рамках документального шага. Имена файлов — свидетельство заявленного
варианта, но не замена паспорту происхождения.
