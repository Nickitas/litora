# 0003 — сокращение стартового web-бандла

- Статус: verified локально; staging/CWV отдельно. Дата: 26.09.2026.
- Область: web; P2 maintenance, без новых зависимостей.

## Проблема

Основной чанк около 528 КБ. Lazy-маршруты уже есть, но layout статически
импортирует docs navigation/constants, а Navbar — Motion для закрытого mobile menu
и scroll progress. Three.js не обнаружен в entry; наличие зависимости в manifest
не означает загрузку в браузере. Не меняем router, темы, UI-kit и API.

## Приёмка

| ID | Требование | Проверка |
| --- | --- | --- |
| WEB-001 | Измеряется весь статический граф entry | raw/gzip + дедуплицированный граф маршрутов |
| WEB-002 | Стартовый граф меньше 400 000 байт raw | analyze:bundle --check; warning threshold не менять |
| WEB-003 | Mobile menu грузится при первом открытии | Loading fallback, повторное открытие/закрытие и переход |
| WEB-004 | Docs navigation загружается только в docs | Lazy docs shell, fallback; прямой переход и навигация |
| WEB-005 | Scroll progress без Motion | Scroll/resize, cleanup listeners/rAF, resize документа |

Сравниваем raw и сумму gzip отдельных JS-файлов; это не сетевой замер/LCP.
Не включаем CSS, шрифты, изображения, API и поздние интеракции.
Baseline: entry 528,45 КБ по Vite. Browser smoke и CWV отдельно от сборки.

## Реализация и измерения

DocsShell загружается на docs-маршрутах. MobileMenu — после первого открытия,
затем остаётся смонтированным для сохранения exit-анимации. Статические индикатор
прокрутки и шапка не требуют Motion. Scroll progress использует passive listener,
requestAnimationFrame, ResizeObserver и cleanup. Темы и mobile animations сохранены.

`pnpm test:bundle` включён в `pnpm verify` (и существующий CI). Отчёт строит
production-граф в памяти, не изменяет dist, не публикует пути хоста. Бюджет проверяет
весь статический entry, а не один файл; возвращение Motion/docs в него также ошибка.
Для docs-маршрутов в `withEntry` учтён отдельный lazy DocsShell. `entryModules`
содержит renderedLength до минификации: это диагностика, не размер сетевого файла.

Замер 26.09.2026: baseline получен подстановкой прежних трёх компонентов из HEAD
через Rollup transform в памяти, без отката рабочей копии; остальные текущие правки
сохранены. В обоих случаях измерялся финальный generateBundle после Vite hooks.

последующую загрузку мобильного меню; она происходит после действия пользователя.
