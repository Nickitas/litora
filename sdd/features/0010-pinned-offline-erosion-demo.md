# 0010 — закреплённое офлайн-демо CERC для web

- Статус: локальная сквозная проверка пройдена; staging не подтверждён.
- Область: Go CLI transport, API worker, тесты и документация.

## Решение

Публичный web-kind `erosion` использует демонстрационный набор Сочи, а не
пользовательские волны/глубины. До этого Go CLI мог скачать свежие данные при
неполном кэше. Хеш результата сохранялся, но повторный запуск мог незаметно
получить другой upstream input.

CLI получает дополнительный флаг `--offline` для демо `erosion`. Он запрещает
сетевой fallback демонстрационного набора и несовместим с `--refresh` и
`--source-url`; для других режимов `erosion` флаг отвергается. Локальный CLI
без флага сохраняет прежнее поведение. Worker
всегда запускает демо с `--black-sea-sochi --offline`; пользователь не может
передать эти или другие CLI-флаги через HTTP.

Перед Go и после него worker проверяет SHA-256 пяти поставляемых файлов:
берегового сегмента, волнового ряда, батиметрии, инвентаря сооружений и
манифеста источников. Ожидаемые digest закреплены в коде API. Отсутствие или
изменение файла → `failed` до публикации успешного результата. Обновление
демонстрационного набора требует review источника и прав, изменения digest,
тестов и этой спецификации. Это версия **содержимого**, не версия научного
метода CERC.

## Проверка и границы

- Go-тест: офлайн-режим отвергает отсутствующий кэш и `--refresh`, не
  обращаясь в сеть.
- API-тест: изменённый/отсутствующий файл отвергается; аргументы worker
  включают только разрешённые офлайн-флаги.
- Сквозной тест должен подтвердить `succeeded` для закреплённого набора и
  сохранённые digest через HTTP → worker → Go → S3.
- Офлайн-режим не подтверждает лицензию, актуальность прогноза, вертикальный
  датум или научную пригодность данных. Демо не становится прогнозом размыва.
- `lito all` и самостоятельный `lito erosion` без `--offline` пока могут
  использовать сетевое обновление; это осознанно сохранённое поведение CLI.

Локально 01.10.2026: `pnpm typecheck`, `pnpm test:api`, `pnpm test:cli`,
`pnpm check:workspace` прошли. В изолированном Compose-проекте прошёл полный
HTTP → worker → Go → PostgreSQL/S3 тест всех четырёх kind; для `erosion`
проверен `--black-sea-sochi --offline` в зафиксированной командной строке.
Контейнеры остановлены, тестовые volumes сохранены без удаления. Staging не
проверен.
