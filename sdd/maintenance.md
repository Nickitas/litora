Для каждого пункта фиксируйте фактическую реализацию в `sdd/` и обновляйте
пользовательские объяснения отдельно в `packages/docs/content/`. `pnpm verify`
проверяет код и структуру, но не заменяет интеграционный тест на отдельной БД/S3.
Корневой `.github/workflows/ci.yml` восстановлен; `check:workspace` теперь
проверяет его наличие. Локальный `pnpm verify` прошёл 25.09.2026, но GitHub Actions
ещё не запускался после этих изменений. Интеграционный job дополнительно зависит
от доступности унаследованного MinIO-образа; при сбое pull требуется заменить dev
S3-стенд, а не скрывать провал теста.
